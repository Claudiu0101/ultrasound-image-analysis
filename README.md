# Fatty Liver Dissertation Presentation

This repository contains the **presentation** for my dissertation on **early detection of fatty liver disease using artificial intelligence**.

## Contents
- `fatty_liver_dissertation_presentation.pdf` – PDF slides of the dissertation.

## Overview
The project focuses on detecting early signs of fatty liver disease from ultrasound images using AI techniques. The dissertation demonstrates applied machine learning methods for medical imaging, highlighting the potential of AI in healthcare.

> **Note:** The dataset and code are confidential and not included in this repository.
