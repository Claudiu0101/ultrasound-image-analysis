# Fatty Liver Dissertation Presentation

This repository contains the **presentation** for my dissertation on **early detection of fatty liver disease using Python**.

---

## Overview
The project focused on detecting early signs of fatty liver disease from **ultrasound images** of patients. The workflow included:  
- Preprocessing **anonymized patient images from hospital datasets**  
- Converting **DICOM files to NIFTI format**  
- Annotation and segmentation using **ITK-SNAP**  
- Data processing and analysis in **Python**  
- Exporting results to **Excel** for interpretation  

**Main conclusion:** signal intensity decreases with depth, confirming the working hypothesis.
